First release: `django-stack init` creates a Docker Compose project with a Django backend (Django Headless and Django Content Studio), an Astro frontend, Postgres, Valkey and Mailpit, with a starter content model, demo content, preview and revalidation. `django-stack doctor` checks a project. `@django-stack/utils` has the typed content client, the preview and webhook signatures, and the image and SEO helpers.
