# Security policy

## Reporting a vulnerability

Report security problems privately through GitHub's
[private vulnerability reporting](https://github.com/dwarsbit/django-stack/security/advisories/new),
or by email to leon@dwarsbit.nl. Do not open a public issue.

Include the affected package and version, the steps to reproduce, and the
impact you see. You get an answer within a week.

## Supported versions

DjangoStack is in early development. Only the latest release of each
package receives fixes.
